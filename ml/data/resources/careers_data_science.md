# Careers in Data Science

Analyst, data scientist, and machine learning engineer are different jobs. Analysts clean data and explain trends. Data scientists prototype models and experiments. ML engineers put models into production with monitoring.

For a computer science graduate in Nairobi, a realistic first role is data analyst or junior ML engineer if you have Python, SQL, and one portfolio project.

A master's is not required for many analyst roles. It helps for research-heavy ML. Salaries vary widely; treat unofficial figures as unverified until you check a primary source.

Build a small end-to-end project: dataset, notebook, simple model, short write-up of limitations.
