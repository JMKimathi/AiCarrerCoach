# Software Engineer CV Template

A strong internship or graduate CV for computer science students is one page. Lead with education (course, expected graduation, relevant modules), then 2–3 projects with impact, then skills, then experience.

Write bullets as action + tool + result. Example: "Built a REST API in Python and FastAPI that cut manual report time from 3 hours to 15 minutes." Avoid listing duties only.

Match the job description: if the posting asks for Git, SQL, and teamwork, those words should appear honestly in your projects. Recruiters in Nairobi and remote teams scan for that overlap in seconds.

Include a GitHub or portfolio link. Do not attach a photo. Keep margins readable and use a single font.
