# Cover Letter Writing Guide

A cover letter should be under 300 words. Paragraph 1: the role and why this organisation. Paragraph 2: one project that maps to their needs. Paragraph 3: availability and a clear ask for an interview.

Do not repeat the CV. Translate coursework into their problem. For a data internship, a class dashboard becomes "I cleaned 2,000 rows and presented trends to a supervisor."

Address a named hiring manager when you can. Close with thanks and your phone number. For Kenyan graduate schemes, mention when you can start and that you can work on-site if required.
