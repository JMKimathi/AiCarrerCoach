# Building a Portfolio Website

Recruiters spend under two minutes on a student site. Show two or three projects, not ten. Each project needs a problem, what you built, the stack, and a link to code or a demo.

Use a simple layout: name, course (for example BSc Computer Science, Strathmore), one-line goal, then projects. Host on GitHub Pages.

Do not hide the GitHub link. Include one project that matches the jobs you want (API, data analysis, or a small ML demo). Write in plain English, not buzzwords.
