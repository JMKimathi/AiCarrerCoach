# Technical Interview Practice: Algorithms

Coding screens usually mix arrays, hash maps, strings, and simple graphs. Talk while you think: restate the problem, give an example, state time complexity, then code.

Start with a brute-force idea, then improve. For internships, correct and clear code beats a clever one-liner you cannot explain.

Practise: two-sum, reverse a linked list, BFS on a grid, and SQL group-by. After each problem, write the Big-O. If you stall, say what you would test next rather than going silent.
