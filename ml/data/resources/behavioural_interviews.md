# Behavioural Interview Question Bank

Use STAR: Situation, Task, Action, Result. Keep answers under two minutes. Prepare stories for teamwork, conflict, failure, leadership, and a tight deadline.

Example: a group project where a teammate missed a deadline. Situation and task first, then what YOU did (re-planned tasks, spoke privately, documented work), then the result (submitted on time, grade, what you would do next time).

Common prompts: "Tell me about a time you failed." "Describe a conflict in a team." "When did you learn a tool quickly?" Practise out loud. Do not memorise a script word for word.
